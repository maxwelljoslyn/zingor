# Zingor

**Zingor** is a multiplayer application for tracking player characters (PCs) in Alexis Smolensk's current online D&D campaign, begun in 2026. This website presents documentation for Zingor's users.

Zingor itself is deployed at [https://zingor.maxwelljoslyn.com](https://zingor.maxwelljoslyn.com).<br>
Read the source code at [https://github.com/maxwelljoslyn/zingor](https://github.com/maxwelljoslyn/zingor).
